🔢 Sudoku

Fill the grid so every row, column and box has 1–9.

📖 How to play

Fill the empty squares with numbers from 1 to 9. Each row, each column, and each of the nine 3×3 boxes must contain every number from 1 to 9, with no repeats. Tap a square, then tap a number (or use your keyboard). Tap a number then the eraser (⌫) to clear. Pick a level and see if you can solve it!

About this game

Sudoku is a quiet number puzzle you can pick up for five minutes or forty. Nine rows, nine columns and nine small boxes all need the digits one through nine, and no digit may repeat inside any of them.

This page builds a brand new puzzle every time you ask for one, so you never meet the same board twice. Each board is tested while it is being made to be sure it has exactly one correct answer.

It suits anyone who likes thinking slowly — a parent with a coffee, a student on the bus, a grandparent who used to do them in the newspaper. Nothing counts down and nothing punishes you for pausing.

How it works

  • A dropdown at the top lets you choose easy, medium or hard, and medium is already selected when the page opens.
  • Harder levels simply start with fewer numbers already filled in, which leaves you more squares to work out.
  • Tap an empty square to select it, then tap a number on the pad placed just below the grid.
  • The eraser key on the pad clears a square, and on a computer the number keys and Backspace also work.
  • The check button turns any wrong square red and tells you how many squares are still empty.
  • Finish the grid correctly and a congratulation message appears straight away, without you pressing anything.

Tips for playing

  • Start by hunting for rows, columns or boxes that already hold seven or eight numbers — the missing digits there are almost free.
  • If a number can only go in one square of a box, place it there, even when that square could also hold other numbers.
  • Thick lines mark the nine three-by-three boxes. Reading a box as one unit, instead of square by square, speeds up your scanning.
  • Guessing works badly here. One wrong digit quietly ruins everything you place after it, so it is faster to prove a number before writing it.
  • The starting numbers are placed symmetrically around the centre of the grid, which is the classic look used by printed puzzles.

Common questions

Does every puzzle have just one answer?

Yes. While the board is being created, a number is only removed if the puzzle still has a single solution. Every square can therefore be worked out by logic, never by luck.

Is it comfortable to play on a phone?

Yes. The grid resizes to fit the screen and the number pad sits underneath it, so everything is reached with a thumb. No keyboard is needed on a small screen.

What should I do when I get stuck?

Use the check button. Wrong squares turn red and you are told how many squares remain. You can then clear anything you doubt with the eraser and try that area again.

Will my grid still be there if I leave the page?

No. The board lives in the page only, so closing the tab ends that puzzle. Asking for a new puzzle also builds a fresh grid, so finish one before you start another.
