🔢 Sudoku

Fill the grid so every row, column and box has 1–9.

Fill the empty squares with numbers from 1 to 9. Each row, each column, and each of the nine 3×3 boxes must contain every number from 1 to 9, with no repeats. Tap a square, then tap a number (or use your keyboard). Tap a number then the eraser (⌫) to clear. Pick a level and see if you can solve it!
