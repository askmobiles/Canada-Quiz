About this game

Times Tables Champion helps a child learn multiplication from one to twelve without pressure. It splits the work into three parts: learning a table slowly, practising with no clock at all, and finally racing the timer for a medal.

The learning part walks down a table one line at a time and shows a memory tip for that table, so a child sees the pattern instead of only repeating numbers. Nothing moves on until they press the button themselves.

It was built for the moment when homework says learn your seven times table and nobody knows where to begin. A parent can sit beside a child, or an older child can work through it alone.

How it works

  • The menu offers three buttons: learn a table, practice with no timer, and a twenty-question challenge.
  • Learn mode shows one line of a table at a time, with a memory tip written above the list.
  • Practice lets you tick one table, several tables or all of them, and it explains every answer as you go.
  • Challenge picks a single table, asks twenty questions against the clock, and awards a bronze, silver, gold or champion medal.
  • Your medals are shown on the main menu, so a child can see which tables still need one.
  • Facts you answer wrongly are remembered, and one button drills exactly those tricky ones again.

Tips for playing

  • The nine times table has a neat check: the two digits of each answer add up to nine, from nine times one to nine times ten.
  • Multiplying by four is simply doubling twice. Six fours becomes six doubled to twelve, then doubled again to twenty-four.
  • Anything times eleven up to nine just repeats the digit, so seven elevens is seventy-seven and nine elevens is ninety-nine.
  • Order does not change the answer, so learning six times eight gives you eight times six for free. That halves the work.
  • Short daily bursts beat one long session. Five minutes before supper sticks better than half an hour on a Sunday afternoon.

Common questions

Which tables does it cover?

Every table from one to twelve. You can learn them one at a time, or tick several at once in practice mode when a child is getting ready for a school test.

Is there a way to practise with no clock running?

Yes, that is exactly what practice mode is for. There is no timer and no pressure, and each answer is explained, so a child can take as long as they need.

How is a medal decided?

A challenge is twenty questions on one table, played against the clock. How many you get right and how quickly you answer decide whether you finish with bronze, silver, gold or champion.

Can a teacher use this in a classroom?

Yes. There are no accounts and no names to type, so a class can begin immediately. Each child works on their own device, and the medals earned stay on that device.
