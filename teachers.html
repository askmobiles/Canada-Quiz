More about using this in class

Nine short answers. Open the one you want.

Nothing to sign up for

A student opens the page and starts. No email address, no username, no password, no class code. Nothing they do is stored on a server, because there is no server — the site is plain pages, and a score lives only in that browser until it is closed.

That usually matters more to a school than anything else on this page, so it is the first thing on it.

Printable worksheets, with answer keys

Choose a topic, a difficulty and how many questions, and the page builds a clean sheet you can print or save as a PDF — with the answer key on its own page, so you can print the class set without it. Eleven topics, three levels, and it works the same in French.

Useful when the devices are booked, the wifi is down, or you want something on paper for a supply teacher.

On the projector

Every quiz and game has a button marked “Play on TV”. It makes the text and the answer buttons much larger, which is what you want on a screen at the front of a room, and it stays on for the next page. On Chrome and Edge it can also cast straight to a Chromecast.

A whole class can play one quiz together from a single screen, with you controlling the pace.

What this is not

It is not aligned to any provincial curriculum, it is not official, and it is not a replacement for your own material. It is a free set of practice questions and games about Canada that happens to be useful in a classroom, built by someone who is not a teacher.

If something on it is wrong, please say so — a correction from a teacher is the most useful message this site receives.

About this page

This page gathers what is on Canada Quiz that a classroom can use, and puts the thing schools decide on first — no accounts and no student data — at the top rather than in the small print.

There are about 3,400 practice questions across citizenship, learner driving tests for every province and territory, general knowledge in nine subjects at three levels, and a fun Canada quiz in nine topics. All of it is free, all of it exists in English and French, and none of it asks anybody to register.

Worth remembering

  • The worksheet builder puts the answer key on a separate page, so a class set can be printed without it.
  • Municipal government — what a town is responsible for and how it pays for it — appears both in the citizenship material and in the town hall game, because it is on the real citizenship test.

Common questions

Do students need an account?

No. There is no login anywhere on the site, for students or for teachers, and no way to create one. Nobody's name, class or score is sent anywhere.

Can I print the questions?

Yes. The worksheet builder makes a printable sheet from any topic and level, with the answer key on its own page. Print it or save it as a PDF from the same dialog.

Is it aligned to the curriculum?

No, and it does not claim to be. Provincial curriculums differ and change; this is practice material you can fit where it is useful, not a course.

Can I put a link to this on our school site?

Please do. There is nothing to ask permission for and nothing to pay. A link from a school or a board also helps other teachers find it.
